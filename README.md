# robbitlink

O'quvchilar va foydalanuvchilar uchun foydali ta'limiy saytlar, onlayn dasturlash muhitlari va resurslar havolalari portali (HTML, CSS, JS).

## 🚀 Imkoniyatlari:
- Foydali saytlar ro'yxati va to'g'ridan-to'g'ri o'tish tugmalari
- Istalgan yangi havolani qo'shish va saqlash (LocalStorage)
- Havolalarni toifalar (kategoriyalar) bo'yicha saralash
- **Dars kodi / Vazifa bo'limi (Read-only)**:
  - O'quvchilar dars kodini bir tugma bilan nusxalab olishlari mumkin (`Kodni nusxalash`).
  - O'quvchilar kodni o'zgartira olmaydi (faqat o'qituvchi admin paroli orqali yangi kod yuklaydi).
- **Parol bilan himoyalangan boshqaruv (O'qituvchi rejimi)**:
  - Havola qo'shish, o'chirish va kodni o'zgartirish maxfiy parol orqali himoyalangan.
  - Maxfiy parol: `7896`
- **Lucide Icons** zamonaviy ikonkalar kutubxonasi
- Chiroyli va qulay zamonaviy dizayn
